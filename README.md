## 🚀 How to Run

1. Install Python 3.
2. Clone this repository.

```bash
git clone https://github.com/Nivi-144/Python-Codes.git
```

3. Navigate to the repository.

```bash
cd Python-Codes
```

4. Run any Python file.

```bash
python filename.py
```
